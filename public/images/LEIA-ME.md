# Onde colocar as imagens

Coloque os arquivos nestas pastas (formato `.jpg`, `.png` ou `.webp`):

- `hero/` — 1 imagem de fundo do topo da página (motorista/carro).
  Recomendado: bem larga, ex. 2400×1600px, orientação paisagem.
- `services/` — até 4 imagens, uma por card ("Para empresários",
  "Para famílias", "Para ocasiões especiais", "Para sua rotina").
  Recomendado: proporção 16:11, ex. 1200×825px cada.
- `experience/` — até 3 imagens para os cards que se sobrepõem ao rolar
  ("Um acolhimento único", "Você dá o tom", "Zero imprevistos").
  Recomendado: bem largas, ex. 2000×1300px cada.

Pode usar qualquer nome de arquivo — depois me diga quais imagens são
para qual card e eu conecto cada uma no lugar certo (trocando os
gradientes de CSS por essas fotos).
